# Barsys Marketing Dashboard

A command center for the Barsys marketing team — managing brand marketing, creator partnerships, and campaign analytics all in one place.

## What's Inside

### Brand & Social Hub (Gosia)
- **Content Calendar** — Plan and schedule social posts
- **Performance** — Track social metrics and engagement
- **Community** — Manage DMs and community interactions
- **Briefs** — Create and track content briefs
- **Activations** — Campaign launches and events
- **Trends** — Monitor trending topics and hashtags
- **Ops Feed** — Real-time operations updates

### Creator & Affiliate Hub (Lexi)
- **Pipeline** — Track creator outreach stages
- **Database** — Full creator profiles and history
- **Campaigns** — Manage active creator campaigns
- **Outreach** — Email and DM outreach log
- **Performance** — Creator content performance metrics
- **Codes & Links** — Affiliate codes and tracking links
- **Roster Health** — Monitor creator relationship health
- **Reports** — Generate creator program reports

### Shared Tools
- **Asset Library** — Shared brand assets and media
- **Collaborations** — Cross-team project workspace
- **Comms Hub** — Internal communications
- **Budget** — Marketing budget tracking

### Analytics
- **Channel Overview** — Cross-channel performance
- **Reports** — Custom analytics reports
- **ROI** — Return on investment tracking

## Features
- Role-based views (switch between Gosia and Lexi perspectives)
- Dark/light theme toggle
- Interactive onboarding tour for new users
- KPI dashboard with real-time alerts
- Collapsible sidebar with help tooltips

## Getting Started

```bash
# Clone the repo
git clone https://github.com/fareed-bit/Marketing-Dashboard.git
cd Marketing-Dashboard

# Install dependencies
npm install

# Start the dashboard
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack
- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Zustand** (state management)
- **Lucide React** (icons)
